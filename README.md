# Labs_Samosyuk_RIS#

## Запуск

bun run cli.js -- --task task1  
bun run cli.js -- --task task1 -i input.txt  
bun run cli.js -- --task task1 -i input.txt -o output.txt  

## Аргументы

- `-t, --task` — обязательный, выбор задачи  
- `-i, --input` — входной файл (если не указан — stdin)  
- `-o, --output` — выходной файл (если не указан — stdout)
