# Labs_Samosyuk_RIS

Передача данных из CLI в функцию решения задачи

## Запуск программы

Примеры команд:

Ввод из консоли -> вывод в консоль:
bun run cli.js -- --task task1

Код

Ввод из файла -> вывод в консоль:
bun run cli.js -- --task task1 -i input.txt

Код

Ввод из файла -> вывод в файл:
bun run cli.js -- --task task1 -i input.txt -o output.txt

Код

Ввод из консоли -> вывод в файл:
bun run cli.js -- --task task1 -o output.txt

Код

## Аргументы командной строки

- `-t, --task` — обязательный параметр, выбор задачи  
- `-i, --input` — путь к входному файлу (если не указан, используется stdin)  
- `-o, --output` — путь к выходному файлу (если не указан, используется stdout)

Для обработки аргументов используется библиотека `commander`.

## Ввод данных

Если входной файл не указан, данные считываются из консоли (stdin).  
В этом режиме программа не завершается после выполнения задачи — можно вводить новые данные построчно.

Если указан входной файл, данные считываются из него.

## Вывод данных

Если выходной файл не указан, результат выводится в консоль (stdout).  
Если указан выходной файл, результат записывается в него.

## Ошибки

Если входной или выходной файл указан, но не существует, недоступен или является директорией, выводится ошибка в stderr, и программа завершается с кодом, отличным от 0.

## Технические требования

- Используются потоки (Readable, Transform, Writable)
- Для обработки используется метод `pipeline`
- Код разделён по файлам:  
  - `cli.js` — обработка аргументов и запуск pipeline  
  - `tasks/` — реализации задач  
  - `utils/` — создание потоков ввода/вывода
